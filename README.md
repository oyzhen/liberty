# 弈境 · 围棋修行

一款可直接在浏览器中游玩的围棋教学与对战应用。以「千局修行」为主线，将规则教学、棋题训练、人机与双人对弈、棋谱复盘、评级考核、灵宠养成和成就收集放在同一方棋枰上。

## 已实现功能

- **1000 关闯关**：十境各 100 关，覆盖 9 / 13 / 19 路棋盘。前段依次引入提子、逃子、连接、双打吃、分断与价值选择，后续加入征子、枷吃、眼位、对杀、扑、倒扑和官子；含目标高亮、星级、提示与逐关解锁。
- **24 课教学**：从棋子、气、提子、禁着点到布局、死活、收官与复盘，并可进入对应实战练习。
- **真实围棋规则**：合法落子、提子、禁自杀、禁覆盖、劫争、悔棋、双方连续停一手与 SGF 导出。
- **对局模式**：五档本地启发式 AI、人机对弈、同设备双人对弈、内部评级考核。
- **棋谱解读**：导入或粘贴 SGF，逐步打谱、自动播放、拖动进度、导出棋谱及本地棋理解读。
- **成长与成就**：修为、棋玉、每日修行、灵宠喂养与改名；20 项成就自动解锁并发放奖励。
- **视听个性化**：13 种主题、2D / 2.5D / 3D 视角、合成音效、4 种生成式背景声景、音量与静音设置。
- **多输入与响应式**：鼠标、键盘、触摸；3D 拖动旋转、滚轮或双指缩放；桌面侧栏与移动端底部导航。
- **可选在线能力**：服务端大模型助教、基于修行码的 MySQL 进度保存与恢复；未供给时自动使用本地模式。

## 快速开始

要求 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

开发服务默认位于 `http://localhost:3000`。

```bash
npm run check   # TypeScript 类型检查
npm run test    # 规则、AI 合法性及全部 1000 关目标测试
npm run build   # 构建浏览器端和独立服务端 bundle
npm run verify  # 静态浏览器冒烟测试、三状态截图与键盘方向断言
```

生产启动：

```bash
npm start
```

生产运行需要有效的 `APP_ID`、`APP_SECRET` 和 `DATABASE_URL`。平台部署时应由平台注入这些值，不要把真实凭据提交到仓库。独立服务端入口为 `dist/boot.js`，依赖已打包，无需复制 `node_modules`。

## 存档与在线服务

- 默认进度保存在当前浏览器的 `localStorage`，不会自动同步到其他设备；清除浏览器数据会删除本地进度。
- 配置 MySQL 后，`progress.save` / `progress.load` 可通过修行码保存和恢复进度。前端先探测 `progress.status`，服务不可用时不反复请求保存接口。
- 大模型助教通过服务端 AI SDK 调用平台网关，模型 ID 在运行时读取，不在浏览器暴露密钥。额度、供给或网络不可用时会返回明确标注的降级提示。
- 本地 AI、规则、闯关和 SGF 功能不依赖在线服务。

## 规则与内容边界

- 终局采用**简化中国面积计分**，白棋贴 6.5 目；当前没有死子标记、人工确认终局和复杂劫争规则面板，因此不应把它当作正式比赛裁判工具。
- 五档 AI 是可离线运行的启发式本地 AI，**不是 KataGo，也不代表职业或真实段位棋力**。内部评级只用于本应用的成长反馈，不等同于官方段位证书。
- 1000 关由 17 类战术棋形确定性组合生成，并逐关验证答案与目标，不是 1000 道逐一人工编写的专业死活题。难度通过技巧顺序、棋盘大小、棋链长度和干扰棋形递进；不是职业级题库。
- 本地棋谱解读不虚构胜率或精确目数。大模型回答也不应被当作专业引擎分析。
- 音频由 Web Audio 实时合成，无需加载外部音频文件。

## 渲染与性能

Three.js 使用实例化棋子、程序化木纹和自适应相机。检测到 SwiftShader、llvmpipe 等软件渲染器时会自动进入兼容模式，降低像素比和棋子几何复杂度，并关闭实时阴影与背景粒子；真实 GPU 保留完整材质与阴影。

无头浏览器中的 SwiftShader 数据只用于正确性和相对开销检查，不能当作真实 GPU 帧率承诺。
